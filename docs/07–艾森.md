## 上位之路

### 石板获取

| 环节 | 详情 |
|------|------|
| 原本 | 不应由他继承石板 |
| 手段 | 通过**某种方式**（陷害？交易？背叛？）从正统继承人手中夺取 |
| 结果 | 借助石板力量**作弊**，在联盟大赛中获胜 |

### 冠军生涯

- 靠石板维持"不败"战绩
- 实际战力**远低于**其他冠军（一旦失去石板就会暴露）
- 极度恐惧与**真正的强者**对战

## 核心恐惧

### 合法性危机

| 恐惧 | 表现 |
|------|------|
| 知道自己不是"真正的冠军" | 每次领奖都心虚 |
| 害怕有人揭露石板的秘密 | 监控所有可能的威胁 |
| 更害怕**真正的继承人**回归 | 参与追杀丝戈尔一家 |

### 石板依赖

- 力量来自外物，而非自身
- 每晚检查石板是否还在
- 做过失去石板、被当众击败的噩梦

## 反派魅力

### 可悲之处

| 过去 | 现在 |
|------|------|
| 可能也曾是热血的训练家 | 被困在"冠军"的假面中，无法脱身 |
| 得到石板前可能有梦想 | 现在只为**保住地位**而活 |
| 不是天生的恶人 | **被权力异化**的普通人 |

### 危险之处

- 为了保住地位**不择手段**
- 对厄戈吾的追杀是**生存本能**，非个人恩怨
- 可能与其他势力（火箭队残余？）交易

## 创作备忘

- ⚠️ **避免脸谱化**：让他有魅力，让观众理解他的恐惧
- ⚠️ **战力设定**：无石板时实力≈普通道馆馆主，有石板时接近一级神
- ⚠️ **结局开放性**：不一定要死亡，失去一切后的**自我救赎**也是选项
- ⚠️ **与厄戈吾的对照**：一个靠作弊上位，一个天生正统，但都不快乐
