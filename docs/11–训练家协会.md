# 🏛️ 训练家协会（Pokémon Trainer Association）

> *"神已沉睡，但羁绊仍在。我们将建立人类与宝可梦的新秩序。"*

---

## 组织概况

| 项目 | 内容 |
|------|------|
| **全称** | 训练家协会（Pokémon Trainer Association） |
| **成立时间** | 约1800年代（1725年神沉睡后约75年） |
| **成立背景** | 皇权逐渐衰落，需要新的社会管理体系 |
| **核心机制** | 道馆制度、联盟大赛、冠军体系 |
| **当前地位** | **世界主导秩序**，管理各地区的训练家与宝可梦对战 |

---

## 历史演变

### 第一阶段：萌芽期（1725-1800年）

| 背景 | 发展 |
|------|------|
| 1725年神沉睡 | 人类陷入信仰危机，但皇权仍维持 |
| 宗教盛行 | 各群体崇拜不同的一级神/二级神 |
| 宝可梦职能 | 承担交通、军事、生产，人类依赖加深 |

**转折点**：皇权逐渐无法管理庞大的宝可梦训练者群体，需要专业组织。

### 第二阶段：建立期（1800-1900年）

- **约1800年**：训练家协会正式成立
- **核心创新**：**道馆制度**——将强大的训练家纳入体系，赋予管理职责
- **联盟大赛**：每年举办，选拔冠军
- **与皇权关系**：初期合作，逐渐独立

### 第三阶段：主导期（1900年至今）

| 特征 | 详情 |
|------|------|
| **皇权消亡** | 训练家协会取代旧秩序，成为实际权力中心 |
| **科技树偏移** | 宝可梦承担交通/军事，人类未发展对应科技 |
| **冠军崇拜** | 冠军成为新的"英雄"符号，填补神之空缺 |
| **石板问题** | 理论上神兽应被协会管理，但1725年后神兽沉睡 |

---

## 核心制度

### 道馆体系

| 层级 | 职能 |
|------|------|
| **道馆馆主** | 各城市/地区的守护者，考验挑战者 |
| **徽章收集** | 训练家需击败8位馆主，获得联盟资格 |
| **属性专精** | 每位馆主专精一种属性，体现基因羁绊 |

### 联盟大赛

- **年度赛事**：各地区举办
- **冠军产生**：最强训练家获得地区冠军称号
- **最终目标**：成为**宝可梦大师**（各地区的最高荣誉）

### 冠军地位

| 权力 | 限制 |
|------|------|
| 地区最高战力象征 | 需接受协会调度 |
| 重大事务决策权 | 不能公开违背协会利益 |
| 石板持有（部分） | 需证明合法性 |

---

## 1725年后的特殊问题

### 神兽管理真空

| 问题 | 现状 |
|------|------|
| 一级神/二级神沉睡 | 协会无法"借用"神兽力量 |
| 幻兽持有石板 | 幻兽不受协会管辖，无权能 |
| 石板散落 | 协会无法集齐，阿尔宙斯未苏醒 |

**结果**：协会是"没有神的神权社会"，依靠**人类训练家体系**维持秩序。

### 2009年后的隐患

- 默若（前火箭队）以合法身份活跃于双龙市
- 艾森（冠军）靠石板作弊，协会未察觉
- 石板收集加速，神兽即将苏醒——协会的体系能否应对？

## 与其他势力的关系

| 势力 | 关系 | 详情 |
|------|------|------|
| **火箭队** | 敌对/轻视 | 以为已灭，未察觉默若的存在 |

- ⚠️ **危机铺垫**：300年无神期即将结束，协会的应对是后期剧情
