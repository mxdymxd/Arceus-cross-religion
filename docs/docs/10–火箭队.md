---

## 历史演变

### 第一阶段：犯罪组织（1900-2000年代）

- 传统宝可梦犯罪组织：盗窃、黑市交易、非法实验
- 与训练家协会对抗，多次被打击
- 首领更替，组织逐渐式微

### 第二阶段：宗教化转型（2000-2009年）

| 转变 | 详情 |
|------|------|
| **核心信仰** | 神已死（沉睡），人类必须自己成为神 |
| **终极目标** | 创造**可控的新神**，取代阿尔宙斯 |
| **理论依据** | 1725年后284年无神的空白期，人类对"神"的渴望达到顶峰 |
| **关键招募** | 默若（22岁，激进基因学家） |

### 第三阶段：2009年事件与覆灭

- **表面**：超梦暴走，实验室全灭，计划失败
- **实际**：默若上位，掌控残余势力，转入地下
- **遗产**：资金、技术、情报网络被默若继承

## 2009年事件后的火箭队

### 表面状态

- 官方认定：已被摧毁，残余势力不成气候
- 训练家协会：未意识到威胁仍在
- 公众记忆：超梦是恐怖传说，火箭队是历史

### 实际状态

| 要素 | 详情 |
|------|------|
| **实际掌控者** | **默若**（自称新老大，但已洗白身份） |
| **资源** | 资金转移至双龙市，建立研究所 |
| **人员** | 核心成员被默若清除或控制，外围不知情 |
| **活动** | 地下基因实验，复活梦幻研究，默思隔离抚养 |
