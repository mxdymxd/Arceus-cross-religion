## 背景故事

### 出生与流亡

| 时间 | 事件 |
|------|------|
| 约2009年 | 母亲**丝戈尔**18岁离家赴帕底亚冒险 |
| 约2010年 | 因调查**故勒顿传说**触犯禁忌，被家族追杀 |
| 2010-2025年 | 与当地掌权家族二少爷隐姓埋名生活，生下厄戈吾 |
| 16年间 | **厄戈吾不知父母真实身份**，以为只是普通冒险者 |

### 与凉脊龙长大

- 童年伙伴是**凉脊龙**（后进化）
- 自然建立深厚羁绊，展现龙系天赋
- 在帕底亚地区**自由成长**，远离家族纷争

### 16岁觉醒（2025年）

| 触发 | 事件 |
|------|------|
| **故勒顿即将苏醒** | 传说与龙属性石板相关 |
| 母亲坦白身份 | 给厄戈吾**家族戒指** |
| 任务 | **带回多拉贡家求助**，应对神兽苏醒危机 |

## 核心冲突

### 继承权斗争

| 规则 | 现实 |
|------|------|
| 家规：长幼不论，**丝戈尔一脉正统继承** | 艾森持有石板，是现任冠军 |
| 厄戈吾是**合法继承人** | 艾森靠石板作弊上位，不愿让权 |

**结果**：厄戈吾回归将直接触发**家族内战**。

### 身份认同危机

| 过去 | 现在 |
|------|------|
| 以为自己是"普通人" | 突然被告知是**古老家族的正统继承人** |
| 自由冒险，无拘无束 | 被迫卷入**政治权谋** |
| 只想和凉脊龙旅行 | 必须学习**贵族礼仪与家族责任** |

- 厄戈吾可能成为默思了解外界的**第一个窗口**

## 创作备忘

- ⚠️ **避免龙傲天**：99%龙属性是天赋也是负担，可能过于依赖龙系宝可梦
- ⚠️ **与默思的对照**：两人是镜像关系，相遇时的张力是剧情高潮
- ⚠️ **故勒顿的伏笔**：神兽苏醒与厄戈吾的回归同步，不是巧合
- ⚠️ **成长弧线**：从"只想变有钱"到接受责任，但保留野性本质
